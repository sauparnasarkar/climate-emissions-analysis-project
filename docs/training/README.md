# Climate Analytics Platform Training

Two companion series cover this project. They share one platform but answer different questions.

| Series | Question it answers | Audience |
|---|---|---|
| [**Technical Series**](technical/README.md) | *How is the platform built?* Data science and ML, the API, Streamlit and React dashboards, the MCP server, and the conversational agent — concepts, implementation, testing, deployment. | Engineers and data scientists building or extending the platform |
| [**Functional Series**](functional/README.md) | *What does the platform tell us about climate change?* The domain, the data sources, the methodology, how the results compare with IPCC/COP/other benchmarks, the Paris Agreement targets, and what the platform's trends imply for them. | Analysts, policy-minded readers, and anyone interpreting the dashboards |

## Suggested reading paths

- **Understand the results:** Functional Series, in order.
- **Build or extend the platform:** start with the [Architecture Overview](technical/00-architecture-overview.md), then the area you need.
- **Both:** read the Functional README for the domain, then the technical Data Science and ML area to see how the data and models are produced.
